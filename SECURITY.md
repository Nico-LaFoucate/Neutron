# Security policy

Please report security problems privately, through GitHub's private vulnerability reporting:

**https://github.com/Nico-LaFoucate/Neutron/security/advisories/new**

Don't open a public issue, discussion or pull request for a security problem.

That link covers all four Neutron repositories: [Neutron](https://github.com/Nico-LaFoucate/Neutron)
(the `neutron` CLI), [neutron-wine](https://github.com/Nico-LaFoucate/neutron-wine),
[Collider](https://github.com/Nico-LaFoucate/Collider) and
[Mud Hut](https://github.com/Nico-LaFoucate/Mud-Hut).

Please include what is affected (which piece and version; `neutron --version` prints them all),
how to reproduce the problem, and what an attacker could do with it.
